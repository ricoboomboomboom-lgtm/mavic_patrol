# Mavic 2 Pro, автономный зигзаг

Проект для Webots R2025a. Миссия стартует сама: взлёт, облёт прямоугольника впереди дрона, возврат и посадка.

## Запуск

1. Установите Webots R2025a.
2. Распакуйте архив целиком. Каталоги `worlds` и `controllers` должны остаться рядом.
3. Запустите `open_webots.bat` или откройте `worlds/mavic_patrol.wbt` в Webots.
4. Нажмите Play.

`mavic2pro_controller.exe` сам по себе не запускают. Без симуляции Windows пишет, что не найден `Controller.dll`. Эта библиотека лежит рядом с exe и в каталоге Webots `lib\controller`. Её подхватывает запуск из Webots.

Каталоги `worlds` и `controllers` должны остаться рядом. Имя контроллера в мире — `mavic2pro_controller`.

В мире уже добавлены акселерометр и высотомер. В штатном прототипе Mavic 2 Pro их нет, без них контроллер миссию не начинает.

Параметры маршрута в начале `mavic2pro_controller.c`: длина 20 м, ширина 10 м, высота 5 м, шаг галсов 2 м, скорость 2 м/с. После правки контроллер нужно пересобрать.

Арена 50×30 м. Дрон стоит в центре, нос по +X, полоса 20 м вперёд и 10 м в ширину остаётся на полу.
